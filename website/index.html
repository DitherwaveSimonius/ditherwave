EXTENSIBLE

Write your own algorithms

Effects run as sandboxed WASM modules, loaded via Extism. Write them in Rust with the ditherwave-plugin-sdk — or in any language that compiles to WASM. No file or network access unless you explicitly grant it.

examples/plugins/invert/src/lib.rs
//! Inverts RGB (alpha untouched), blended
//! against the original by `strength`.

use ditherwave_plugin_sdk::*;

#[plugin_fn]
pub fn apply(Json(request): Json<PluginRequest>)
    -> FnResult<Json<PluginResponse>> {
    let pixels = match decode_pixels(&request) {
        Ok(p) => p,
        Err(e) => return Ok(Json(PluginResponse::err(e))),
    };

    let strength = request.params
        .get("strength")
        .and_then(|v| v.as_f64())
        .unwrap_or(1.0) as f32;

    let mut out = pixels;
    for px in out.chunks_mut(4) {
        for c in px[..3].iter_mut() {
            let original = *c as f32;
            let inverted = 255.0 - original;
            *c = (original + (inverted - original) * strength)
                .round().clamp(0.0, 255.0) as u8;
        }
    }

    Ok(Json(encode_response(&out)))
}
plugin.toml
[plugin]
key = "examples.invert"
display_name = "Invert (example plugin)"
category = "special"
version = "0.1.0"
author = "ditherwave contributors"
wasm = "invert_plugin.wasm"

[[params]]
key = "strength"
display_name = "Strength"
kind = "float"
min = 0.0
max = 1.0
step = 0.01
default = 1.0

Plugins live in ~/Library/Application Support/ditherwave/plugins (macOS) and show up in the effect list automatically — the stack doesn't distinguish between built-in and loaded. Reference plugins live under examples/plugins/ in the repo.
